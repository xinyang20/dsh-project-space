# DSH Space 首版功能与作用

## 作用

为 DeepSeek Harness 提供按工作区组织的项目资料与成果库。把不同会话中的输入资料和生成成果登记在同一个资源页，便于找回、预览、查看来源，并在后续会话中复用。

## 首版功能

- 一个工作区对应一个 Space，会话切换后仍能查看该工作区已有资源。
- 输入资料和生成成果分别展示，支持名称搜索和文件类型筛选。
- 支持上传参考文件、登记工作区内已有文件，以及通过模型工具明确登记生成成果。
- 支持 Markdown、纯文本、PDF 和常见图片预览；其它文件提供元数据和下载。
- 每条资源记录文件名、用途、添加时间和来源会话。文件缺失时明确显示状态。
- 可将资源引用加入当前工作区的会话草稿；由用户决定何时发送。
- 可移除登记记录，保留原文件。
- 资源索引持久保存，宿主重启后仍可读取。

## 边界

- 这是本地项目资源库；首版不提供云端同步、公开分享或文档协同编辑。
- 登记现有文件只接受所属工作区内的真实文件。上传文件保存到插件管理的资料目录。
- 来源会话是明确记录的关联，不推断某个输入一定导致某个输出。
- 首版不自动扫描所有修改文件，不包含历史版本回滚或语义检索。
- 不修改 DSH 核心，不替换既有侧边栏，使用官方插件生命周期、公开 UI 插槽和宿主服务。

## 验收场景

1. 在工作区 A 上传 PDF／图片，分别登记参考资料和生成成果，搜索和筛选结果正确。
2. 切换到 A 的另一会话，仍能访问同一批资源；工作区 B 看不到 A 的资源。
3. 文本中的 HTML 不执行；图片和 PDF 可预览；未知格式可下载。
4. 将资源加入当前草稿，不自动发送；可以返回资源的来源会话。
5. 刷新页面和重启隔离宿主后，资源仍在。
6. 删除原文件后显示缺失；移除记录不会删除文件。
7. 工作区外路径、路径穿越和越界符号链接被拒绝；超限上传有明确错误。
8. 真实 DSH 安装与启动验证通过，真实浏览器完成主要使用流程。

## 开发文件边界

所有源码、依赖、缓存、临时文件、测试工作区、隔离 DSH_HOME、测试结果和交付包均放在此 dsh-space 子目录内。开发与测试不使用用户现有的 DSH profile、会话或凭据。
